## 2. 优先级
- **P0**：首发必须完成。
- **P1**：首发后近期迭代。
- **P2**：验证核心业务后再开发。
- **Blocked**：依赖资质、商户号、第三方服务或业务决策。

## 5. API 清单

### 公共 API
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/health` | 健康检查 |
| GET | `/api/v1/home` | 首页聚合数据 |
| GET | `/api/v1/countries` | 国家列表 |
| GET | `/api/v1/cities` | 城市列表 |
| GET | `/api/v1/routes` | 路线列表、筛选、分页 |
| GET | `/api/v1/routes/:slug` | 路线详情 |
| GET | `/api/v1/products` | 商品列表 |
| GET | `/api/v1/products/:slug` | 商品详情 |

### 用户 API
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/auth/wechat` | 微信登录 |
| GET | `/api/v1/me` | 当前用户 |
| GET | `/api/v1/me/collections` | 收藏列表 |
| POST | `/api/v1/collections` | 收藏路线 |
| DELETE | `/api/v1/collections/:routeId` | 取消收藏 |
| POST | `/api/v1/orders` | 创建订单 |
| GET | `/api/v1/orders` | 我的订单 |
| GET | `/api/v1/orders/:orderNo` | 订单详情 |
| GET | `/api/v1/orders/:orderNo/files` | 已购文件下载地址 |
| POST | `/api/v1/itineraries` | 创建行程 |
| GET | `/api/v1/itineraries` | 我的行程 |

### 支付 API
| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/payments/wechat/prepare` | 创建支付单 |
| POST | `/api/v1/payments/wechat/notify` | 微信支付异步通知 |

### 管理 API
前缀：`/api/v1/admin/`。资源包括 countries、cities、routes、route-stops、transport-records、travel-notes、visa-records、products、product-files、orders、audit-logs。所有管理写接口鉴权；发布接口校验必填字段、节点顺序、内容等级和来源。

## 6. 测试计划

### 单元测试
- 路线筛选组合和节点排序。
- 金额计算与订单快照。
- 支付签名验证。
- 重复支付通知幂等性。
- 文件下载权限。

### 集成测试
- 国家/城市/路线 CRUD。
- 草稿不会被公开接口读取。
- 已发布路线可公开读取。
- 创建订单到支付成功状态流转。
- 已支付订单文件授权。
- 非本人订单拒绝下载。

### E2E 测试
1. 游客：首页 → 探索 → 路线详情。
2. 用户：登录 → 商品详情 → 创建订单。
3. 支付成功 → 我的订单 → 下载资料。
4. 管理员：登录 → 创建路线 → 审核 → 发布 → 小程序展示。

### 安全测试
未登录访问管理接口、普通用户访问管理接口、篡改订单号/商品 ID、重放支付通知、伪造前端支付成功状态、访问他人订单文件、上传超大文件或非法 MIME 类型。

## 8. Codex 执行约定
1. 每次只实现一个可验收模块，不要求一次性生成完整平台。
2. 开始前阅读 `docs/PRD.md`、`docs/DATABASE.md` 和本文件。
3. 先给实施计划及文件改动清单，再编码。
4. 不得编造旅行事实、交通价格、签证政策或用户数据。
5. 数据库变更必须生成迁移文件。
6. 写接口必须有权限校验和输入校验。
7. 支付、订单、文件交付先写测试再实现。
8. 完成后报告改动文件、实现说明、测试结果、未完成项和风险。
9. 不得把密钥、商户证书或真实用户数据提交到 Git。
10. 未通过 lint、typecheck 和相关测试，不得标记完成。
